# جملتي | Jomlati — Daily English PWA v0.3

## محتوى النسخة التجريبية
- 120 جملة إنجليزية مع ترجمة عربية وشرح استخدام واختبار مفردة.
- أربعة مسارات: المحادثات اليومية، العمل والمقابلات، الدراسة والجامعة، السفر والتنقل.
- مستويات مبتدئ ومتوسط ومتقدم.
- جملة يومية ثابتة حسب التاريخ والمستوى المختار.
- النطق عبر SpeechSynthesis في الجهاز، المفضلة، التقدم، وسلسلة التعلم.
- تخزين محلي ودعم PWA للعمل دون اتصال بعد أول زيارة.

## التشغيل المحلي
من داخل المجلد شغّل: `python -m http.server 8000` ثم افتح `http://localhost:8000`.

## النشر
ارفع محتويات المجلد كاملة إلى Cloudflare Pages كملفات ثابتة. تأكد من رفع `sentences.js` أيضاً.

## حدود النسخة
لا يوجد بعد تسجيل دخول أو مزامنة سحابية أو تحليلات استخدام أو دفع أو إعلانات. التذكير المحلي يعمل أثناء فتح التطبيق؛ التنبيهات عند إغلاقه تحتاج Push API وخدمة خلفية. بيانات التقدم محفوظة على الجهاز فقط.
